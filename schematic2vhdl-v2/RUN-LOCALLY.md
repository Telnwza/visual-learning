# เปิด Schematic Studio v2 ในเครื่อง

ตัว editor ใช้ HTML, CSS และ JavaScript ที่อยู่ในไฟล์เดียว เปิดใช้งานออฟไลน์ได้ ไม่ต้อง build หรือติดตั้ง npm

## เปิดผ่าน localhost

บน Mac เครื่องนี้มี Python 3 อยู่แล้ว เปิด Terminal แล้วรัน:

```sh
cd "/Users/te/Documents/Code/visual-learning"
python3 -m http.server 8000 --bind 127.0.0.1
```

เปิดเบราว์เซอร์ไปที่:

```text
http://127.0.0.1:8000/schematic2vhdl-v2/
```

ระหว่างใช้งาน ให้เปิด Terminal หน้านั้นไว้ เมื่อเลิกใช้ให้กด **Ctrl+C** ใน Terminal เพื่อหยุด server ครั้งต่อไปก็รันคำสั่งเดิมแล้วเปิด URL เดิม

ถ้าย้ายโฟลเดอร์ ให้เปลี่ยนพาธในคำสั่ง `cd` ตามตำแหน่งใหม่ ถ้าพอร์ต 8000 มีโปรแกรมอื่นใช้อยู่ ให้เปลี่ยนเลขพอร์ตทั้งในคำสั่งและ URL เช่น 8001

บน Windows ที่มี Python อยู่แล้ว ใช้ `py -m http.server 8000 --bind 127.0.0.1` จากโฟลเดอร์ `visual-learning` แล้วเปิด URL เดียวกัน

## เปิดไฟล์ตรง ๆ

เปิดโฟลเดอร์ `schematic2vhdl-v2` แล้วเปิด `index.html` ด้วยเบราว์เซอร์ได้เลย วิธีนี้ไม่ต้องรัน server

ถ้าจะใช้งานต่อเนื่อง แนะนำ localhost ด้วย URL และพอร์ตเดิม เพื่อให้กลับมาใช้พื้นที่ autosave เดิมได้สะดวก

## ย้ายงานจากเว็บมาใช้ในเครื่อง

1. ที่เว็บเดิม กด **File → Save Workspace** เพื่อเก็บไฟล์ `.schproj.json`
2. เปิด Schematic Studio v2 ในเครื่อง
3. เลือก **File → Open Project / Workspace…** เพื่อโหลดงานจากไฟล์ หรือ **Import Workspace…** เพื่อรวมเข้ากับงานที่เปิดอยู่

Autosave ของเว็บ GitHub กับ localhost แยกกัน รวมถึงการใช้คนละเบราว์เซอร์ คนละพอร์ต หรือสลับระหว่าง `localhost` กับ `127.0.0.1` ถ้าเปิดแล้วไม่เห็นงานเดิม ให้นำไฟล์ workspace เข้ามา

ถ้ามีโค้ด VHDL ที่ยังแก้ค้างอยู่ ให้ Apply การแก้ไขก่อน Save Workspace เพราะ draft ที่ยังไม่ได้ Apply ไม่ได้รวมอยู่ในไฟล์ workspace

## เก็บไว้ใช้กับเครื่องอื่น

ตัว editor ใช้เพียงไฟล์ `schematic2vhdl-v2/index.html` คัดลอกไฟล์นี้กับไฟล์ workspace ไปเปิดในเครื่องอื่นได้เลย ถ้าต้องใช้โมดูลที่เตรียมไว้ ให้นำโฟลเดอร์ `fpga-exam-kit/modules` ไปด้วย

ใช้ **Save Workspace** เก็บงานเป็นไฟล์ก่อนย้ายเครื่องหรืออัปเดตตัวโปรแกรม แล้วนำไฟล์นั้นไป Open หรือ Import ในเครื่องปลายทาง
