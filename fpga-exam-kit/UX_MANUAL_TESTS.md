# รายการทดสอบ UX ด้วยตัวเอง

วันที่ 20 ต.ค. 2026 · เก็บไว้อ้างอิง ผู้ใช้ให้ข้ามการตรวจละเอียดเพิ่มเติมแล้ว รายการนี้ไม่ใช่เงื่อนไขก่อนทำงานต่อ ช่องที่ยังไม่ติ๊กหมายถึงยังไม่ได้ยืนยันผ่านหน้าจอจริง

เปิด [Schematic Studio](../schematic2vhdl-v2/index.html) แล้วใช้ **File → New Project** สร้างโปรเจกต์ทดสอบ จะได้แยกจากวงจรที่ใช้อยู่

ไฟล์โมดูลอยู่ใน [all-vhdl-modules](modules/downloads/all-vhdl-modules/) มี `.vhd` ทั้งหมด 49 ไฟล์

## 1. เลือกไฟล์ 49 ตัวพร้อมกัน

ใช้โปรเจกต์ใหม่ชื่อ `test_import`

- [ ] กด **Import Module…** ต้องเปิดหน้าต่างเลือกไฟล์ทันที
- [ ] เลือก `.vhd` ทั้ง 49 ไฟล์ แล้วกด Open ต้องได้โมดูลครบใน Components โดยไม่มีหน้า Preview/Apply เพิ่ม จำนวนชิ้นส่วนกับสายบน canvas ต้องเท่าเดิม
- [ ] ค้นหา `ss_reg_pipo`, `ss_counter_skip`, `ss_lcd16x2` ต้องเจอทั้งสามตัว
- [ ] นำเข้า 49 ไฟล์เดิมซ้ำ ต้องข้ามทั้งหมด ไม่มีโมดูลชื่อซ้ำ
- [ ] ทันทีหลังนำเข้าซ้ำ กด Undo หนึ่งครั้ง ต้องย้อนการนำเข้าชุดแรกทั้งหมด แล้ว Redo หนึ่งครั้งต้องได้คืนครบ 49 ตัว การนำเข้าซ้ำต้องไม่เพิ่มขั้น Undo

## 2. ขาดไฟล์ แล้วเลือกเพิ่มต่อ

สร้างโปรเจกต์ใหม่อีกอันชื่อ `test_recovery` เพื่อให้ยังไม่มี LCD writer

- [ ] นำเข้าเฉพาะ `ss_lcd16x2.vhd` ต้องแจ้งว่าขาด `ss_lcd_write` และยังไม่มีโมดูล LCD ถูกเพิ่มเข้าโปรเจกต์
- [ ] กด **เพิ่มไฟล์…** แล้ว Cancel ในหน้าต่างระบบ รายการ `ss_lcd16x2.vhd` ที่รออยู่ต้องยังอยู่
- [ ] กดเพิ่มไฟล์อีกครั้ง เลือก `ss_lcd_write.vhd` ต้องนำเข้าทั้งสองโมดูลได้เลย โดยไม่ต้องเลือก controller ใหม่ และไม่วางกล่องลง canvas เอง
- [ ] Undo หนึ่งครั้งต้องเอาออกทั้งสองตัว Redo ต้องคืนทั้งสองตัว

## 3. ไฟล์ชื่อ entity ชนกัน

กลับไปโปรเจกต์ `test_import` ที่มีครบ 49 ตัว

ทำสำเนา `ss_bus_reverse.vhd` ไว้นอกโฟลเดอร์โมดูล แล้วแก้เฉพาะในสำเนาจาก `y(i)<=d(WIDTH-1-i)` เป็น `y(i)<=d(i)` โดยคงชื่อ entity เดิมไว้

- [ ] นำเข้าสำเนานี้ ต้องแจ้งชื่อ entity ชนกัน ไม่เขียนทับ source เดิม และไม่เพิ่มกล่องหรือสาย
- [ ] ยกเลิกรายการที่รอนำเข้า แล้วนำเข้าไฟล์ต้นฉบับอีกครั้ง ต้องข้ามเป็นไฟล์เดิมที่มีอยู่แล้ว

## 4. ยกเลิกหน้าต่างเลือกไฟล์

- [ ] กด Import Module… แล้ว Cancel ต้องกลับมาทำวงจรต่อได้ ไม่มีกรอบนำเข้าว่างค้าง จำนวนโมดูล ชิ้นส่วนและสายต้องเท่าเดิม

## 5. Browser zoom 125%

ปรับ zoom ของ **เบราว์เซอร์** เป็น 125% จากเมนูหรือแถบสถานะของเบราว์เซอร์ ปุ่ม zoom บน canvas ใช้แทนข้อนี้ไม่ได้

- [ ] เลือกโมดูลที่มี generic หลายช่อง เช่น `ss_counter_skip` แล้วลองเลื่อน Inspector ต้องแก้ค่าทุกช่องได้ ไม่มีข้อความหรือปุ่มซ้อนกัน
- [ ] ลองใส่ค่าที่ผิดขอบเขต ต้องเห็น error และแก้กลับได้
- [ ] บนโมดูลที่ต่อสายแล้ว ลองเปลี่ยน WIDTH ให้ต่างจากสายเดิม ต้องเลื่อนไปถึงผลกระทบและปุ่ม Apply/Cancel ได้ พอกด Cancel ค่าและสายต้องกลับเหมือนเดิม
- [ ] ลองย่อความกว้างหน้าต่างด้วย ปุ่มหลักยังใช้ได้ แล้วคืน browser zoom เป็น 100%

## 6. ประกอบ → ดาวน์โหลด → Save/Open

ใช้ `ss_bus_reverse` เป็นตัวอย่าง

- [ ] หยิบจาก Components ตั้ง `WIDTH=64` แล้ววางได้ใน flow เดียว กด Esc ระหว่างเตรียมวางต้องยกเลิกได้
- [ ] ใช้ I/O Marker ติดที่ขา `d` และ `y` ต้องได้ IN/OUT ขนาด 64 บิตพร้อมสาย จากนั้น Check ต้องได้ **0 errors / 0 warnings**
- [ ] เปลี่ยนชื่อ schematic เป็น `test_latest_top` แล้วกด Generate VHDL จากนั้นกด `.vhd` ในแท็บโค้ด เปิด **ไฟล์ที่ดาวน์โหลดจริง** ต้องพบ `entity test_latest_top is`, พอร์ต `63 downto 0`, `WIDTH => 64` และ source ของ `ss_bus_reverse`
- [ ] ย่อขยายกล่องด้วยมือ แล้ว **File → Save Workspace** ตรวจว่ามีไฟล์ `.schproj.json` ถูกบันทึกจริง
- [ ] **File → Open Project / Workspace…** เลือกไฟล์ที่เพิ่งบันทึก โมดูล WIDTH=64, IN/OUT, สาย ตำแหน่ง ขนาดกล่อง และ source ต้องอยู่ครบ แล้ว Check ยังผ่าน

ถ้าเบราว์เซอร์แสดงหน้าต่าง Save หรือถามเรื่องดาวน์โหลด ให้จัดการหน้าต่างนั้นจนได้ไฟล์ก่อนนับว่าผ่าน

## 7. ลองใช้งานทั่วไปอีกหนึ่งรอบ

- [ ] คลิกวางและลากวางทั้ง gate, VHDL module และ schematic ย่อย ตั้งค่า ย้าย และ duplicate กลุ่ม แล้ว Undo ต้องกลับได้ครบ
- [ ] ลองต่อสาย 1 บิตทับ input ที่มีสาย 64 บิตอยู่ ต้องปฏิเสธและรักษาสายเดิม ส่วน fan-out และการลากต่อหลายขาต้องยังใช้ได้
- [ ] เปิด schematic ย่อยจากสอง instance สลับกลับ parent ต้องจำ pan/zoom ของแต่ละแผ่น กด Fit ที่ parent แล้วสลับไปกลับอีกครั้งต้องคงมุมมองหลัง Fit
- [ ] เปิดโปรเจกต์ lab เดิมที่ใช้จริง ลองเข้า schematic ย่อยและบันทึกเป็นสำเนา แล้วเปิดสำเนากลับมา ชิ้นส่วนกับสายต้องครบ

## ส่วนที่ตรวจผ่านแล้ว

- ชุดทดสอบอัตโนมัติ **733/733** ไม่มี skip รวม import/recovery/conflict/Undo, วงจร 64 บิต และ save/load ผ่านตัวอ่านไฟล์ของแอป
- ไฟล์ lab เดิมทั้ง 5 ชุดอ่านและบันทึกกลับผ่านตัวแปลงข้อมูลได้ ต้นฉบับไม่เปลี่ยน
- วงจร `ss_bus_reverse` 64 บิตประกอบผ่าน UI และ Check ผ่านแล้ว ไฟล์ VHDL ที่ดาวน์โหลดจริงนำไป compile/elaborate/simulate ด้วย GHDL ผ่านแล้ว
- แก้บั๊ก Fit แล้วสลับแผ่นกลับมาคืนมุมมองเก่า พร้อม regression test แล้ว

ถ้าเจอปัญหา จดเลขข้อ ขั้นตอนที่กด และผลที่เห็นไว้ จะตามแก้ได้ตรงจุด
